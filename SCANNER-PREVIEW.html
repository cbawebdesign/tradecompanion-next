How it behaves. Four sessions — PRE / MKT / AH / ON — with the current one auto-expanded, ringed in the accent blue and glowing; the rest collapse to a header. Inside each, six market-cap columns from Nano to Mega, each split into gainers then losers. A row is flag, ticker, % change, price; clicking it sets the selected symbol so the data ribbon follows, and the flag toggles without selecting. Empty buckets say “No alerts” rather than disappearing, so the grid stays stable as hits arrive.

Worth knowing. Hits arrive over SignalR as ScannerAlert and are held in the store, capped at 500 and persisted — so a refresh keeps what's already there, but anything that fired while TC was closed is lost, since the scanner is broadcast-only with no endpoint to catch up from.
